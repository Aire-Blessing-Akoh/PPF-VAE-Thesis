METHODOLOGY NOTE (added after initial publication): this file originally reported two separate
bugs, now both fixed. (1) Experiment 4's detection threshold loaded as None from the saved
checkpoint, producing a degenerate always-flag-as-anomaly detector and the trivial
"100.00/100.00/0.00/0.00" rows seen in earlier versions of this file. (2) The FGSM/PGD attack
implementation perturbed each sample to MAXIMIZE reconstruction error, which is backwards for a
genuine evasion threat model (a real adversary wants to MINIMIZE reconstruction error so malicious
traffic is misclassified as benign). Both experiments below have been re-evaluated with the correct
threshold and the attack direction corrected (x_adv = x - epsilon * sign(grad)). Experiments 1 and 2
are not included in this file and have not been evaluated under the corrected methodology.

SUMMARY: Under the corrected (genuine-evasion) attack direction, PPF-VAE (Experiment 4) is
genuinely more robust than the non-federated Centralized+DP baseline (Experiment 3) at the
strongest tested FGSM perturbation -- a 76% reduction in accuracy drop (2.55 pp vs. 10.60 pp) and a
68% reduction in attack success rate (3.90% vs. 12.05%). This confirms the original qualitative
finding with revised magnitudes (previously reported as a flat "70% reduction" / 1.56 pp / 1.68%,
based on the uncorrected attack direction). Compare against BCCC-Mal-NetMem/adversarial_comparison.txt,
where the corrected-direction result shows the opposite pattern (PPF-VAE more vulnerable, not less)
-- the effect of DP-SGD on adversarial robustness is dataset-dependent, not a universal co-benefit.
